# TechNexus Solutions — Sistema Interno

Projeto full-stack acadêmico desenvolvido por Camila Viana e Guilherme Silva.

O sistema oferece funcionalidades de cadastro e gerenciamento de clientes e funcionários, estruturado em arquitetura separada entre Back-end (Java 21 + Spring Boot) e Front-end (React + Vite), com comunicação via API REST.

---

## Como executar

### Back-end
```bash
./mvnw spring-boot:run
```

### Front-end
```bash
npm install react-router-dom axios react-toastify
npm run dev
```

A aplicação ficará disponível em:
http://localhost:5173
